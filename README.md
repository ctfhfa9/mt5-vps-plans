## 挂 MT5 到底需要什么配置

内存是最先要算清楚的一项。MT5 从 2020 年起只提供 64 位版本，而且自 2025 年 7 月起 build 4755 成为强制版本，旧终端连不上经纪商服务器——所以买 VPS 前先确认你的终端已经升级。资源占用方面，MT5 存储真实 tick 数据而不是 MT4 那种 M1 近似值，同等设置下内存消耗大约是 MT4 的 3 到 4 倍。

按 MQL5 开发者社区的实测口径：一个终端、2–4 个图表、一两个 EA 的标准负载，2GB 内存不够用，4GB 才有余量。这就是为什么很多便宜的 2GB 套餐标着「支持 MT4/MT5」，实际跑起来却很勉强。

CPU 方面有个容易搞反的点：MT5 会给每个 EA 和每个品种各分配线程，但一个扫描 28 个货币对的多品种 EA，依然在单线程里跑。所以对大多数零售用户来说，主频比核心数更重要，4 核配一个低频 CPU 不如 2 核配高主频。硬盘倒不太用纠结，25–40GB SSD 对 MT5 绰绰有余。

还有一点常被忽略：MT5 通过远程桌面（RDP）连接，Windows、macOS、Linux、iOS、Android 都能登，VPS 本身不需要你额外准备一台 Windows 电脑。

## 下单与开通流程

流程本身不复杂，几个环节提前知道会顺利很多：

1. 选好套餐进入购物车，填写 hostname 和 root 密码（密码要求包含字母、符号和数字）。
2. 选择支付方式并完成付款，走支付宝或银联的新客户无需额外验证。
3. 等待开通邮件，通常 15 分钟内，最长 2 小时。
4. 用邮件里的 IP、账号密码通过 RDP 登录，Windows 自带「远程桌面连接」即可，Mac 和手机用官方 Microsoft Remote Desktop。
5. 登录后下载安装 MT5，登录经纪商账户，把 EA 拖上图表，开启「自动交易」，最后确认系统不会自动休眠或安装更新重启。

一个容易翻车的细节：开通时账单姓名地址务必填真实信息，反欺诈系统对乱填的订单会人工延迟处理。
